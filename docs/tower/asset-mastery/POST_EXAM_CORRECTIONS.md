# Post-examination corrections — separate from sealed attempts

The six first attempts, eleven visual forms, all raw results and native clips
remain unchanged at the sealed 6329cfa tool revision. Their static conversion
success does not establish animation compatibility or artistic fidelity.

The first reconstruction recipes had no authored rig. The exporter consequently
cleared vertex/face skin labels, even though the component generator supplied
groups. Native play successfully decoded/rendered the model, but source classic
controls had no group to transform. The candidates remained stationary while
the authentic sources moved. The first runner's successful-command status must
not be interpreted as successful reconstruction animation. A separate corrective
motion audit records this failure without editing any sealed result.

After all six processes finished, an explicit preserve_authored_groups recipe
flag was added. It preserves supplied classic group labels for a private
reconstruction without pretending it has an independently authored rig. A
separate face_group property represents alpha-control ownership independently
from vertex ownership. Existing original rigged recipes and default static
exports retain their previous behavior.
When a source has no face-alpha groups, preserve_face_groups=false retains
vertex ownership without inventing face-alpha membership on the reconstruction.

The initial correction proof uses the same Fire Giant 2075 candidate: bind
vertices and all five native images remain identical, while all 48 native
attack samples agree exactly with the independent integer tracer and 45 differ
from the initial pose. This proves the missing ownership path is corrected;
it does not establish faithful anatomy, topology or choreography. Source controls
are reused privately for a modeling test. Original Tower animation remains a
separate independently authored deliverable. The 41 existing unit tests pass.

The corrected candidates are development retests of examined assets, never new
held-out successes. Exact source revision and new module hashes are recorded
with those retests. Independent cached weighted retargeting for Akkha remains
unsupported; authentic source cached clips render through the native client.

The sealed Fire Giant folder label club_variant is a working study label, not
an authoritative weapon identification. Exact identity is NPC 2075; its default
animation set is the non-sword fire-giant set in the consulted symbols. The
selection and original label are preserved, with the interpretation disclosed.

The first full-floor export also exceeded a native model section's u16 byte
length. Its failed output/log is preserved. The corrected original terrain is
split into actual Blender/native mesh chunks rather than changing the encoder
or hiding a rendering defect. Large foundation cap triangles then exposed an
occlusion problem in player views; the geometry is revised into local cells.
No global renderer or authoritative client parity behavior is changed.
