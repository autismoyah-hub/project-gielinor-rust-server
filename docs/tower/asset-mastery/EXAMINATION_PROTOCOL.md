# Six advanced cases — protocol before detailed inspection

The reserved families are Fire Giant, General Graardor (Bandos), K'ril Tsutsaroth
(Zamorak), Xarpus, Verzik Vitur and Akkha. Tooling is frozen before any detailed
geometry/animation examination of these identities. Exact revision 239.1 NPC
IDs and available phases are resolved from the native cache catalog after that
tool freeze, then the identity manifest is sealed before candidate generation.
Select modeled encounter variants; record unavailable/transform-only variants.
Do not invent a replacement or silently change the intended boss.

The first attempt uses the frozen descriptor reconstruction method developed
on the existing calibration corpus: native group/material regions, 3–12 coarse
section observations and a new consistent ring topology. Target-derived shape
observations are supplied. This is **data-assisted private reconstruction**,
not blind semantic understanding and not a direct cache mesh import/export.
Original Tower counterparts are separately authored and must not use those
observations, geometry, source frames or reconstructed derivatives.

The frozen tool module hashes, source revision, native binary SHA256, baseline
and prior source model payload hashes are recorded before examination. Any
model-payload overlap is reported as contamination rather than replaced. The
exam runner rejects changed modules/binary and existing attempt directories.
Every first attempt and failure is retained. A fix after inspection is a named
development retest and cannot establish unseen generalization for that case.

Measure front, side, rear, quarter and gameplay views with matched native
cameras, scale and lighting. Record silhouette IoU, foreground color error,
internal edge agreement, coarse component proportions, geometry counts/bounds,
material representation, source hashes and custom identities. Keep these
measurements separate; no universal quality score grants artistic approval.

Render complete source action durations through animate-complete. Source NPC
definitions establish idle/walk. Additional attacks, specials, transitions and
death require verified local configuration/script evidence, not guessed IDs.
Render every identified eligible action; record missing associations explicitly.
Classic source controls can be applied privately to new group-compatible
topology for a modeling/motion fidelity comparison at the same native ticks.
That does not establish independently authored choreography. Cached weighted
source motion may render authentically while independent weighted retarget is
unsupported; report both outcomes. Do not substitute an unrelated classic clip.

For each original counterpart, use the separately authored native rig and a
complete applicable action set with a distinct second attack or presentation.
Record originality, design rationale, geometry/IDs/hashes, source generation
script, complete native pose coverage and motion diagnostics. Artistic quality
remains under review. Gameplay integration is not tested or authorized here.

Protected references, direct reconstructions, recipes, source frames and mixed
imagery remain private. Publish source tools, safe aggregate reports and genuinely
original models/animations/wholly original imagery. Once the advanced attempts
and counterparts exist, proceed to the complete offline Floor One mockup.
