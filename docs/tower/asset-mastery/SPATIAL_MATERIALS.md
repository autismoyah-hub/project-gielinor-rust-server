# Local native material placement

The post-examination authoring revision adds explicit spatial face-color brushes.
Each owned component can declare material_zones with an authored native XYZ
center, positive radius and packed HSL code. Face centroids inside the nearest
normalized brush receive its value; other native face colors remain unchanged.
The result is real Blender face material data and survives the normal native
export. Alpha, priority, texture mappings and global lighting are not altered.

Original designs use independently authored positions and palette choices.
The heat-scarred inspection cover exercises soot, replacement iron and corrosion
regions on separate joined plates. It passes saved/reopened Blender and all
five native views. Refined original foundry retorts use authored heat/soot zones.
The API does not turn a face-colored model into a textured or PBR material;
coarse polygons can still make color boundaries visibly angular.

For private reconstruction development retests, coarse source-region material
observations may supply brushes. Such descriptors, recipes, geometry and imagery
are protected derivatives and must stay private. This is data-assisted color
placement, not independent original asset authorship or an unseen generalization
result. All six sealed first attempts remain unchanged. Later material and
group corrections are labeled development retests with their own hashes.

The original material path without brushes is unchanged. The 43 unit/boundary
tests include the previous 41 and local face-edit/range contracts. Native
rendering remains the appearance authority; no image-space correction or global
renderer adjustment is used to conceal a modeling defect.
