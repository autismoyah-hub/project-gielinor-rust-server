# Asset and treatment decisions

Twenty-five authentic native-library boards compare actual local cache references. Their source scenes and exact camera metadata are in [asset-comparisons](asset-comparisons/index.json); their rendered images remain in the local gallery. Names and footprints came from actual cache metadata searches and the final clipping audit, not assumptions from an ID's name.

| Decision | References tested | Visual finding |
|---|---|---|
| Dressed wall family | 6010, 6098, 6132, 6145, 13069, 13072 | Prefer 6132 with 6143 low boundaries. Plain 6145 is too blank; 6098 exposes bars from the reverse angle and reads as confinement. Do not judge a wall only from one side. |
| Structural piers | 7016, 7017, 2440 | 7017 provides the weight and cap rhythm; the small timber-like 2440 does not support the intended masonry language. |
| Work surfaces | 609, 610, 2279 | Prefer the heavier fitted 610 bench. The lighter 2279 loses visual mass against the wall. |
| Furnace | 2030, 37947, 18526 | 2030 has a clear working mouth and useful forge scale. Keep 18526 only as the distant foundry cue. This is a visual choice; production action binding is not changed or accepted. |
| Rest seating | 1104, 1106, 5615 | Fitted 1106 benches replace the log-like 1104 silhouette. The hearth seats face inward; service seating sits against the room edges. |
| Bank | 18491, 6084, 4483 | 6084 is more restrained than the bright frame and still reads as a counter. No bank implementation is replaced. |
| Fire | 16811, 2732, 11017, 11020, 28817, 27361 | One communal 16811 hearth; smaller 11020 iron braziers mark arrival and destination. Avoid repeating ceremonial hearths as generic lamps. Frames are static samples, not animation acceptance. |
| Repair scar | 6915, 5569, 6011 | Reject 6915: its actual model reads as a dark wedge/structure. Use low 5569 stone with sparse 1173 ferns. |
| Supply/repair props | 21442, 16474/16475, 5574, 362/363/718/672, 327, 15936 | Group bins, fuel, sacks, vessels, spare wheel and handpump beside the work they explain. The tested 1812 model showed an unrelated glowing effect and is excluded. |
| Waterwheel | 18511 | Retain real 1×3 wheel, inspect its face and foundation from multiple approaches. No driven machinery or flowing water simulation is claimed. |
| Terrain | 377/545, 364/1245, 232/880, 232/885, 322/578, 400/1555, 425/1278 and six patterned sources | Prefer textured paving plus dark work surface. Several patterned sources produced void-like or strongly striped fields in the native renderer; visible rendering results overrule promising metadata. Large grass patches were also rejected for this interior sequence. |

The chosen study has 219 location records, mostly structural boundaries, plus deliberate work/stay/repair groupings. More objects alone is not the quality criterion. Several cache objects expose operations that this detached scene does not bind to server gameplay.

The software license does not grant Jagex media rights. As in the prior review, no cache-derived PNG/BMP, extracted model/texture, raw cache archive or account data is published. Public diagrams use only our own geometry and typography; scene files contain authored coordinates and asset references. Authentic imagery is retained locally for the user's visual review.
