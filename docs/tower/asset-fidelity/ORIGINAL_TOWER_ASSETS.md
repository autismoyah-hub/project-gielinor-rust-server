# Original Cinderworks assets

Published recipes/geometry/native models/actions/standalone renders are under
`art/tower/production-fidelity`. MANIFEST.json records hashes and authoring source.
No cache mesh, animation, texture, direct reconstruction recipe or protected
Blender derivative is included. Editable original Blender files remain local;
the published original recipes regenerate them headlessly. Previous original
Tower probes are preserved in their earlier directories and source history.

| Original | Native vertices / faces | Experimental identity |
|---|---|---|
| Sluice keeper arcade | 544 / 980 | model 1101525, object 63425 |
| Counterweight sluice hoist | 1035 / 1874 | model 1101526, object 63426 |
| Kilnback Rummager | 760 / 1264 | model 1101527, object 63427, NPC reservation 60027 |
| Supporting terrain | 2160 / 4020 | model 1101528, object 63428 |

The arcade has bonded masonry, radial voussoirs, a keystone, gate guide rails and
an iron repair tie. The hoist has a coopered drum, trestles, bearings, crank,
ratchet/pawl and counterweight. These are original construction studies; no
moving machinery simulation is claimed. The creature has a longitudinal organic
body/neck/muzzle, six three-joint legs, pads/claws, overlapping ceramic plates,
vents, curved mandibles and tail. Its six action clips are documented separately.
Supporting paving, runoff channel and timber crossing form an eight-by-six-tile
offline vignette; they replace no map tile.

All four survive saved/reopened Blender byte-exact model export. Owned native
quantization cleanup removes 56 hoist, 36 creature and 12 terrain zero-area
triangles; arcade needs none. All preserve vertex order and group identity.
Native object-package loading matches all 20 direct views. The creature has 368
exact independently traced pose samples, a pixel/coordinate-exact entry bridge
and 105 unchanged classic payload files compared with the pre-clean revision.
Cleanup changes owned lighting/face topology, so old/new model pixel identity
is not claimed. Native IDs are experiment reservations, not live registration.

The clean actor is a second complete headless generation of the six-action
design after support/bridge development. Pre-clean and clean geometry share
vertices and all classic payload bytes; each build independently passes native
encoding/reopen/pose checks. Reports retain both versions. No art approval is
implied by compiler, preservation or packaging success.
