# Original asset gate

No new asset is approved for Tower integration by the reference-platform results.
The planned bounded proof is an original structural asset, an original industrial
prop and an original creature with supported actions. They must be authored from
owned components and measured style observations, not modified cache meshes.

Original candidates must be rendered beside authentic assets in shared native
conditions and reviewed at close and gameplay scale. Their publication boundary
is distinct from reference reconstructions, which remain private. Artistic
acceptance and production integration require separate decisions.

The current evidence establishes conversion and analysis. It does not yet
establish this original-creation milestone.
