# Isolated native Cinderworks vignette

The showcase combines the new arcade, counterweight hoist, animated Kilnback and
original terrain with genuine revision 239.1 context: furnace object 6189,
barrel 362, soil 325, low wall 6143 and Man NPC 3106 with native idle 808.
It reads the original cache without modifying it. No server, world, account,
live map or gameplay system is involved. The full floor remains suspended.

`showcase.py` writes an explicit TSV manifest and calls the actual Rust client
model-combine/software-render path through native `scene`. A single light
configuration (ambient 64, contrast 768) and common native cameras apply to
both genuine and owned models. Original meshes use native units: arcade about
242 tall, hoist 150, human about 190 and creature about 80. This demonstrates
scale coexistence, not the maturity of a complete environment production kit.

Evidence includes overview 1440x960, reverse 1280x900, and three actual native
player-camera 765x503 views: entrance, workbench and creature. Three scene clips
contain 62 native renders: walk 17, attack 15, death 30, with original ticks and
declared walk travel. The final death frame holds the corpse. The protected local
review links every still, GIF, manifest and scene provenance output.

An early authentic rock choice was grossly oversized; that scene is preserved
and excluded from the final composition. Terrain bank gaps and bridge reach
were corrected in separate owned revisions. Later sole support/entry and mesh
cleanup revisions generated a fresh final scene. No failed scene was overwritten.

The final scene is deliberately small and simple. It demonstrates new materials,
scale, architecture and motion beside native scenery. It does not prove complete
Floor One environmental storytelling, collision, navigation or artistic approval.
Authentic assets and mixed scene images stay private; standalone wholly original
models/renders/actions are published. Rebuild with locally authorized cache data
using ATELIER_HANDOFF.md. No public screenshot containing authentic scenery is
included in the repository.
