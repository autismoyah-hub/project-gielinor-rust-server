# Separate fidelity measurements

Technical B preservation checks exact decoded channels, submitted world geometry,
rendered pixels, native float32 pose coordinates and alpha. Reopening Blender
is mandatory. B tests 51 unique static variants/255 views and the existing
26 source action sets/468 timestamps; new static cases add no source actions.
Original-owned compiler agreement is a separate 368-pose test.

Independent C diagnostics use fixed A cameras/lighting and report whole-object
foreground IoU, bounds and surface differences at front/side/rear/quarter/gameplay
views. These never auto-approve art. A box can score highly while missing joinery.

`component_review.py` takes explicit private semantic face bindings and calls
native `mask`. Native occlusion, priorities, alpha and geometry stay active;
textures are disabled only for the selected-face ID mask. White selected faces
and black context give visible component silhouettes. A uses the exact preserved
B geometry fixture, so no approximate second renderer is introduced.

Reports separate component bounds/IoU, region mean native RGB/distance,
foreground-union RGB error and internal image-edge precision/recall at 2-pixel
tolerance. Edge agreement depends on lighting, texture and geometry; it is not
a topology or artistic score. Bindings and diagnostic masks remain private.
Scimitar blade mean IoU 0.633 versus fittings 0.189 exposes a specific weak grip
and guard; anvil horn 0.577 exposes contour error; barrel wood 0.605 exposes
construction/texture mismatch hidden by whole-body volume overlap.

Motion measurements include foot sole height/drift, support hull, declared
root travel, body centroid proxy, head forward/recovery, pose displacement,
rigid component deformation and persistent terminal shape. No static bounding
overlap is mislabeled as intersection detection. Integer rotation quantization
can produce small edge changes. Unsupported self/equipment collision stays
explicit. Read ANIMATION_AUTHORING.md for the exact final protocol/results.

Frozen result provenance contains tool/client/native hashes, selected IDs,
original definition/model payload hashes and split overlap checks. A later
development correction is a new result directory and never repairs history.
All earlier rejected studies remain reviewable. Artistic judgment is reserved
for the user, independent of geometric similarity and technical preservation.
