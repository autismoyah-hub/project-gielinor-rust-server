# Generalization protocol

Nine held-out assets are predeclared in the executable reference catalog. Their
statistics are excluded from training summaries. Before evaluation, freeze the
authoring tool version, record recipe inputs and check raw-model payload overlap.
The two training swords sharing model2604 cannot count as separate geometry
generalization. Held-out raw mesh reuse is prohibited in independently authored C.

This checkpoint has not yet run held-out authoring. Later results must identify
whether fitting used target descriptors or manual corrections. A new class that
requires an added archetype is evidence of a limitation, not a retroactive held-out
success. After tuning on it, that asset becomes a development example; a new
untuned cohort is needed to test the revised method.

Passing reference conversion on held-out data would certify only preservation,
not convincing independent models or readiness for original Tower production.
