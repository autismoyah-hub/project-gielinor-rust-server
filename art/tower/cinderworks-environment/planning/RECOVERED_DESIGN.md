# Recovered Cinderworks environment contract

Current Rust source, not the superseded eleven-row Kotlin diary, defines the active journey: restore Forge, Kitchen and Altar in any order; defeat the Imp; quench and defeat the Warden; claim the existing first/replay reward; use the existing portal. The personal `tower_run` state, recovery and persistence are retained.

The existing floor occupies local tiles32–79 on both axes, origin(10368,64,0). This assignment preserves all gameplay anchors. The recommended A–H structure is reconciled to the existing wings rather than migrating persistent coordinates. Reward and departure sites intentionally remain attached to the sanctuary; moss and reclaimed water occupy their two established wings.

New proposals are architecture, machinery composition, geology, connected industrial utilities, low foreground walls and local scenery. No new reward, hazard damage, combat controller, NPC model or animation is introduced. Existing cache terrain and functional entities remain protected runtime dependencies.

Planning JSON files record the room registry, connectivity, full traversal, mandatory/optional activities, props, walkability and asset dependencies before detailed modeling. Cache-backed collision and native traversal remain required acceptance work.
