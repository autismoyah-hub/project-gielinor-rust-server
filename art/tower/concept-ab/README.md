# Ashhorn Stalker — controlled original NPC comparison

Open [the blind A/B review](index.html) first. Use its technical reveal only
after recording your visual assessment. Both models share the exact design in
`design.json`; its hash is in`design.sha256`.

Editable final sources, static native payloads, camera definitions and native
and studio views are in`models/A` and`models/B`. Initial, intermediate and final
checkpoints are in`history`. `registry.json` describes isolated diagnostic
identities; nothing is installed in the live game. Every mesh and generated
concept image here is original. No protected cache mesh or texture is included.

The technical reveal contains concept variants, exact prompts, consistency
assessment, source links, effort, geometry comparisons, limitations and the
provisional workflow recommendation. User artistic approval remains pending.
The local private review additionally includes matched authentic courtyard
renders and detailed verification records, excluded from Git publication.

Reproduction instructions and tool provenance are in
`tools/tower/concept-ab/README.md`. This is a single unequal-effort pilot, not
proof that either method should become the standard production pipeline.
