# Original Tower asset probes

Three independent designs exercise the developing authoring workbench. They are
not accepted production art and are not integrated into the live Tower. Recipes,
owned geometry, native models, authored classic action descriptions and standalone
native renders may be reviewed here. No cache mesh, cache animation or authentic
comparison image is included. The private review contains shared native scenes
with genuine assets. Technical export does not establish artistic fidelity.

Generate the recipes with `original_designs.py`; use `author_workflow.py` without
`--reference` to create saved Blender scenes, new registration packages and native
views. Rebuild classic action payloads from each `actions/*.json` using
`native_codec.classic`. See the ATELIER handoff for complete commands and limits.
