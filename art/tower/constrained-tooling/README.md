# Original authoring-tool examples

These are reference-free construction demonstrations, not approved game assets.
They start from factory-empty Blender scenes and read no game/reference meshes.

* **Reed Runner:** connected profile anatomy, independent muzzle, fitted saddle
  surface, local landmark deformation and retained construction cages.
* **Long-muzzle variant:** changes the same muzzle controls; the body mesh remains
  byte-equivalent, demonstrating component locality.
* **Harvesting bill:** a strongly hooked, variable-width diamond-section blade,
  guard, grip and cap. The tight bend exercises transported-frame continuity.

Each folder includes its recipe, editable Blend, native model, construction
metadata and six unchanged-native-renderer images. The images contain only these
original meshes and the renderer's plain background. No cache payloads,
reference images, runtime palettes or reconstruction assets are included.

See `tools/tower/constrained/README.md` and `cookbook.py` for generation and checks.
`manifest.json` records the delivered artifact hashes.
